# 分岔路口 · Forking Paths

一个把两种选择放到同一张地图上的交互式网页。你为两条路打分，调整评价维度的重要程度，就能看到当下的倾向，也能保存当时的想法，日后重新打开。它是一张权衡地图，不预测未来，也不替你做决定。

**在线体验：** https://gonndxx.github.io/forking-paths/

## 体验

打开 `index.html` 即可使用，无需账号、后端或 API Key。部署在静态网站托管服务上也可直接运行。

## 功能

- 自定义问题和两个选项，或使用三个示例场景
- 自定义 2–6 项评价维度，分别给两条路打分并调整权重
- 实时更新综合分、对比路线图、关键分岔点和可能改变倾向的单项评分
- 保存最多 20 份选择快照，重新打开或删除；当前编辑状态也会自动保存
- 通过链接分享当前选择
- 导出 1200 × 675 PNG 选择卡
- 适配手机与桌面，支持键盘操作和减少动态效果偏好

## 本地运行

项目是无依赖的静态网页。在仓库根目录开启任意静态服务器即可；也可以直接打开 `index.html`。分享链接需要部署后的网址，剪贴板操作在 HTTPS 或 localhost 上体验最佳。

## 隐私

输入的内容和快照默认只保存在当前浏览器的 `localStorage`，不跨设备同步。清除浏览器数据会丢失快照。点击“分享当前选择”会把当前问题、维度、评分和权重编码进链接，持有该链接的人可以读取这些内容；链接不包含快照。请勿在问题或选项里输入不想分享的敏感信息。

## 设计原则

综合分是你自己输入的分数按权重计算的平均值，并非客观预测。接近的结果会明确提示“仍然很接近”。视觉化的作用是让取舍更容易讨论和反思。
